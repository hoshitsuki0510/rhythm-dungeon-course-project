# 《律动遗迹》世界观与叙事

更新时间：2026-08-26

> “心核”为开题阶段暂称；森林、区域、主角、怪物和 Boss 的正式名称与造型仍可在美术设计阶段调整。

## 一句话世界观

> 一片异世界森林依靠遗迹深处如心脏般跳动的“心核”维持生命；怪物窃取心核力量后，森林逐渐凋亡，玩家必须深入遗迹、击败窃取力量的怪物，让心核重新跳动并复苏整片区域。

## 背景设定

这座遗迹并不只是一座废弃建筑，而是古代文明为包裹、保护并引导“心核”力量而建造的巨大生命结构。心核位于遗迹最深处，外形像一颗巨大的心脏。它持续搏动，将生命力沿着地下脉络输送到地表，使森林中的植物、生物和水源维持活力。

遗迹中的节拍并非普通音乐，而是心核搏动在建筑与地脉中的回响。机关、守卫和进入遗迹的生物都会受到这股节律影响，因此玩家也必须依照心跳般的拍点移动、攻击或蓄力。

后来，一群怪物侵入遗迹并不断吸收心核力量。心核的搏动因此变得微弱、混乱，地表森林失去生命供给，颜色逐渐褪去，树木和水源开始凋亡。越接近遗迹深处，窃取的力量越集中，节拍也越容易被扭曲。

玩家进入凋亡区域，沿遗迹向下探索。击败怪物会释放它们窃取的生命能量，使能量重新流向心核。最终，玩家需要击败盘踞在心核附近、能够操控其节律的首领，让心核恢复稳定搏动，并使生命力重新流回整片森林。

## 玩家目标

- 短期目标：清除当前房间中正在吸收生命能量的怪物，打开继续深入的道路。
- 中期目标：利用心核残留的回响获得局内强化，形成适合本局的战斗方式。
- 最终目标：到达遗迹最深处，击败操控或寄生心核的 Boss，修复心核并复苏地表区域。
- 失败条件：玩家生命值耗尽，本局结束，局内强化全部清空。
- 胜利结果：Boss 被击败，心核重新稳定跳动，凋亡区域出现复苏反馈，本局结算后临时强化归还或消散。

## 世界观与玩法的对应关系

| 世界观设定 | 玩法表现 |
|---|---|
| 心核像心脏一样搏动 | 全局 BPM 和节拍提示；玩家必须按心跳般的节奏行动 |
| 怪物吸收心核力量 | 战斗房中的敌人以及玩家继续深入的理由 |
| 击败怪物释放生命能量 | 清房时能量粒子回流、房门开启；不要求普通战斗必定掉落强化 |
| 心核残留的回响 | 奖励房中的二选一局内强化 |
| 局内强化只供本次深入使用 | 胜利或失败后强化返回心核或随本次连接中断而消散，不形成永久养成 |
| Boss 操控被窃取的核心力量 | Boss 改变玩家移动、攻击和蓄力所依据的 BPM |
| 心核重新稳定跳动 | 通关后的节拍稳定、光线扩散、颜色恢复和植物复苏 |
| 越深入节律越不稳定 | 后续多层结构、不同 BPM 与难度递增的叙事依据 |

## MVP 中的叙事表达

两周版本不制作复杂对话、长篇剧情或大型过场，只用少量高辨识度的视觉和文字完成叙事：

1. **起始房：**用两三句文字说明森林凋亡、心核失常和玩家需要深入遗迹。
2. **环境表现：**地表或起始画面使用低饱和、枯萎的色彩；越接近心核，墙面出现类似血管或根系的发光纹路。
3. **清除战斗房：**敌人消失时释放少量光点，沿地面纹路流向遗迹深处，说明力量正在回归，而不是强制掉落强化。
4. **奖励房：**由心核回响形成两个临时能力，玩家选择其中一个继续本局。
5. **Boss 房：**背景中直接出现虚弱或被束缚的心核；Boss 切换 BPM 时，心核搏动、界面提示与音乐一起变化。
6. **通关反馈：**Boss 消失后，心核先恢复稳定心跳，再以颜色、光波或植物生长表现区域开始复苏。

最低版本只需要一个简短开场和一个数秒的复苏结尾，就能说明玩家行动的意义。森林全地图逐步变化、完整动画和多层叙事都属于非 MVP 扩展。

## 暂未确定

- 森林或异世界区域的正式名称。
- “心核”的最终名称、外形细节和来源。
- 主角是外来探索者、当地守护者还是遗迹修复者。
- 怪物为何侵入以及 Boss 是窃取者、寄生体还是失控守卫。
- 古代文明建造遗迹的历史和多层区域主题。

这些内容不影响两周 MVP 的核心闭环，后续应结合像素美术、敌人设计和老师反馈逐项确认。
