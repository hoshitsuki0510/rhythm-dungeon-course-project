## 计划交付格式

- macOS：`.dmg`，内部包含 Universal 2 `.app`。
- Windows：优先导出 x86_64 `.exe` 与同目录 `.pck`，随后整体打包为 `.zip`。
- `DMG` 和 `EXE` 不是互相转换；它们由同一个 Godot 项目使用不同平台的导出模板分别生成。

## 跨平台验收要求

- macOS 构建：在本机从 Finder 启动并完成一轮游戏。
- Windows 构建：必须由用户在自己的另一台实体 Windows x86_64 电脑上完成启动、输入、音频、存档路径和完整流程测试；本项目不准备或使用 Windows 虚拟机作为验收环境。
- 每次正式构建记录 Godot 版本、Git 提交、导出日期、目标平台和测试结果。
