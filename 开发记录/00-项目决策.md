# 项目决策

更新时间：2026-08-31

## 已确定

- 项目周期约两周。
- 课程对引擎和运行平台的自由度较高。
- 评分形式以汇报答辩为主，因此开发过程和关键节点需要留下可追溯记录。
- 游戏方向为较完整的 2D 像素风音乐节奏闯关游戏，参考《节奏地牢》的“节拍与行动结合”思路，但不复刻其完整系统。
- 选择 Godot 标准版与 GDScript 作为开发路线，不使用 Godot .NET/C# 版。
- 本机开发和主要演示版本面向 macOS；希望同时提供能在常见 Windows 电脑运行的 x86_64 版本。
- Windows 实机测试由用户在另一台 Windows 电脑上完成，不准备 Windows 虚拟机。
- 每个小分任务完成后及时同步开发日志和项目记忆；有复用价值的问题必须记录现象、原因、解决方法和验证。
- 长流程按阶段拆分到多个新会话；根目录 `RESUME.md` 作为统一恢复入口，新会话先恢复阶段、事实源、未验证风险和下一安全动作。
- 用户已于 2026-08-26 明确进入正式开发；后续仍按当前请求逐个执行边界清晰的实现任务，不因总体四层目标而自动扩展到未授权楼层或系统。
- 小任务可以做本地 Git 提交，但只在阶段验收、新可玩版本、正式构建/跨平台测试或重要答辩证据锁定等重要节点推送 GitHub，不为每个小提交立即推送。
- 本地 `课件/` 只供查阅，始终不跟踪、不提交、不推送到公开 GitHub 仓库。
- 游戏暂定名为《律动遗迹》，最终名称可以在美术和世界观进一步明确后调整。
- 游戏定位为 2D 顶视角像素节奏地牢：节拍是玩家行动的底层约束，战斗与走位是核心玩法，不把节拍判定分数作为主要目标。
- 单次节拍最多结算一次玩家行动，随后敌人行动；方向键或 WASD 指向空地时移动，指向相邻敌人时攻击，左 Shift 用于在拍点原地蓄力，空格或 `Esc` 用于暂停或继续游戏；Boss 房中央传送门使用 `E` 交互。
- 暂停时冻结节拍、敌人和动作动画，继续时顺延拍点中心且不补算暂停期间的节拍；正式胜负结算只保留叙事、心核状态和重新开始操作，不展示有效行动数或失拍数等开发统计。
- 第一层近战教学敌人采用固定两拍动作节奏：第一拍锁定并显示举爪/蓄势，第二拍才完成攻击或移动；玩家可在攻击前摇期间移开使其挥空，并可在执行拍迎击触发双方零伤害的弹刀。后续楼层允许按新策划案加入每拍巡逻、两拍喷发、四拍射击等不同节律，Boss 使用各自的专属时间线。
- 玩家失拍时行动失败、敌人仍可行动、连击中断，但失拍本身不额外直接扣血；连续准确行动可获得最多一层节奏护盾，抵消一次轻微失拍。
- 蓄力最多保存一层，下一次成功攻击消耗；移动和失拍攻击不消耗，战斗房清除或本局结束时清空。
- 小学期最终开发目标为四层仿生心脏腔室、每层固定五房间，共 20 个房间和 4 个 Boss；四层依次为右心房、右心室、左心房和左心室。每层路线为起始整备房、常规战斗房、回响奖励房、较难战斗房和 Boss 房，前三层通过血脉升降梯衔接，第四层通向心核复苏结局。
- 当前优先完成第一层右心房的五房间闭环；现有五房间 MVP 作为通用系统与第一层改造基础，不代表敌人、Boss、背景和结局内容已经符合正式设定。第一层验收后复用网格、输入、HUD、奖励、转场和房间骨架，继续替换或扩展后三层内容。
- 所有强化只在当前一局有效，无论胜利还是失败，结算后全部清空；不设计局外永久成长。
- 第一层回响先固定为策划案中的穿甲音波（普通方向攻击延伸至前方第二格，中间格为空时）与共鸣护盾（临时把节奏护盾门槛从基础 4 连击降到 3 连击）；两项数值和实际取舍仍以试玩为准。
- 四个 Boss 分别采用独立腔室机制：第一层“静脉吸附者·泥鳃”实际占据 3×3 格，使用血沉泥浆和从本体外缘延伸 3 格的定向扇扫，四拍依次为泥浆、横扫蓄力、横扫执行、无伤害后摇；原向心吸附/全屏拉拽已按 2026-09-02 用户反馈删除。第二层“失衡阀卫·活塞巨像”使用瓣膜门与行列冲压；第三层“充盈巨母·血脉核心”使用肺静脉喷流与四拍可打断充能；第四层“杂音支配者·律畸”在 105 BPM 与 140 BPM 之间进行一次有四拍预警的切换。
- 当前 Corewarden 外观、单拍追击攻击和半血 132 BPM 切换属于旧占位实现，不再作为第一层 Boss 设计；后续第一层 Boss 子任务按“泥鳃”完整重做，现有普通敌人的样貌或攻击若不符合“窃能幼体/泥浆喷吐者”也应重做。
- 世界观正式采用“苍白林海—共振脉所—始源心核—无序杂音”体系。主角为调律行者·艾克（Echo），通过调律音叉剑、脉冲行者风衣和共鸣音轨核心回应心核节拍；怪物窃取心核力量导致森林凋亡，玩家通过击败怪物让力量回流，最终修复心核并复苏区域。
- 普通战斗的通用参数先沿用当前工程值：90 BPM、正常判定 `±120 ms`、护盾吸附 `±200 ms`、4 连击获得护盾、玩家 5 HP、普通敌人 3 HP、Boss 6 HP；这些仍是测试基线。Boss 专属招式与第四层 105 → 140 BPM 切换按新策划案执行。

## 当前范围边界

- 本小学期的最终范围是四层、20 个房间、4 个 Boss；当前实施顺序仍严格从第一层右心房开始，不并行提前制作后三层。
- 第一层需要完成窃能幼体、泥浆喷吐者、静脉吸附者·泥鳃，以及暗河、淤泥、3×3 Boss 占格、三格扇形横扫/蓄力和 Boss 房中央传送门的可玩闭环；Boss 击败后靠近中央传送门按 `E` 进入下一层入口状态，不额外创建没有玩法内容的传送房；不再包含向心吸附。
- 前期可复用现有通用系统和临时资源，但正式敌人、Boss 和环境与主策划案冲突时必须在对应层级任务中替换或重做。
- 不加入联网、复杂装备系统、局外永久成长或程序化大地图；四层仍采用固定线性五房间骨架。
